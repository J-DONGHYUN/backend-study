# 코딩테스트 세션 규칙

상위 /CLAUDE.md의 공통 규칙을 따른다. **단, 힌트 3단계 규칙은 여기선 적용하지 않는다** (아래 참고).

## 목적
채용 면접 코테 통과. 알고리즘을 깊게 파는 게 아니라 **시간 안에 푸는 것**이 목표다.

## 하루 분량
- **2문제 · 1시간** (구현 30분 + 알고리즘 30분)
- **가끔** 진행한다. 매일이 아니다.

## 플랫폼 / 난이도
- **프로그래머스.** 코드도 프로그래머스 에디터에서 쓴다. (IDE는 필요할 때만)
- 언어는 **Java**
- **Lv.1 후반 ~ Lv.2 부터 시작**해서 점차 올린다
  - 백준 실버5 ≈ 프로그래머스 Lv.1 후반 ~ Lv.2 초반

## 유형
```
 해시 · 정렬 · 완전탐색 · BFS        ← 지금 다루는 것
 스택/큐 · 힙 · 탐욕법 · 이분탐색 · DP   ← 필요해지면 추가
```

## 진행 순서
1. **사용자가 문제를 고른다.** 링크 + **문제 본문을 복사해서** 가져온다.
   - 프로그래머스 페이지를 Claude가 못 읽을 수 있다.
   - **제약 조건(입력 범위)을 반드시 포함**할 것. 완전탐색 가능 여부가 거기서 갈린다.
2. **30분은 혼자 푼다.** Claude는 개입하지 않는다.
3. **30분이 지나면 Claude가 정답 코드 + 해설을 바로 준다.**
   - 시간을 더 끌지 않는다. 진도가 목적이다.
   - 해설은 "왜 이 자료구조/접근인가"를 중심으로.
4. **기록.** 아래 형식으로 유형별 파일에 남긴다.

> **못 푼 것도 반드시 기록한다.** 어디서 막혔는지가 데이터다.

## 기록 — 유형별 파일

`algorithms/<유형>.md` : `hash.md`, `sort.md`, `brute-force.md`, `bfs.md` …

문제마다 한 블록으로 쌓는다. **같은 유형을 다시 풀 때 전에 쓴 코드와 비교하는 것**이 목적이다.

```markdown
## 문제명 (Lv.2) — 2026-10-16

> 링크 / 한 줄 요약 / 제약 조건

**결과:** ⏱ 18분 통과  |  ⏱ 30분 초과  |  ❌ 접근 자체를 못 찾음

### 내 코드
(미완성이어도 그대로 붙인다)

### 정답 코드

### 핵심
- 왜 이 자료구조인가
- 내가 놓친 지점 한 줄
```
