# CS 공부 세션 규칙

상위 /CLAUDE.md의 공통 규칙을 따른다. 아래는 CS 전용 규칙이다.

## 로드맵 (아래에서 위로, 과제에서 막힌 주제는 앞당길 수 있음)
1. java : JVM, GC, String/불변성, equals/hashCode, 컬렉션 내부, 예외, 동시성 기초
2. network : TCP/UDP, HTTP/HTTPS, REST, 쿠키/세션/JWT, DNS, CORS
3. os : 프로세스/스레드, 동기화, 메모리, 컨텍스트 스위칭, I/O 모델
4. db : 인덱스(B+Tree), 트랜잭션, 격리 수준, 락, 정규화, 실행 계획
5. spring : IoC/DI, AOP, 빈 생명주기, 트랜잭션 전파, 영속성 컨텍스트, N+1, 지연 로딩
6. design : 계층 구조, 테스트 전략, 캐시, 동시성 이슈, 로깅

## 매일 구술 면접 (5~10분, SQL 테스트와 같은 자리)
매일 짧게 하는 루틴이다. 아래 "한 주제당 세션 흐름"과는 별개로 돌린다.

1. `_progress.md` 에서 **🟡 1개 + 🟢 1개**를 고른다. (🟢는 마지막 학습일이 일주일 지난 것)
2. **2단으로 묻는다.** 실제 면접이 이 순서로 들어온다.
   - 개념: "XXX가 무엇인가요?"
   - 경험: "당신은 그걸 어떻게 적용했나요?" ← 과제 코드에서 실제로 끌어내게 한다
3. 사용자가 **면접관 앞에서 말하듯** 답한다. 짧게, 더듬어도 그대로 쓴다.
4. **꼬리 질문 1개.** 면접관은 반드시 한 번 더 판다.
5. 채점 후 `_progress.md` 갱신.
   - 🟢 30초 안에, 경험 예시까지 붙여서
   - 🟡 개념만 또는 경험만
   - 🔴 말이 안 나옴
6. 답변 기록은 **해당 주제 노트**에. **노트가 없으면 그때 만든다.**
   (질문이 노트를 만드는 트리거가 된다)

## 한 주제당 세션 흐름 (30~60분)
1. **복습**: 🔴/🟡 주제 중 1~2개를 짧게 질문 (🟢도 1주 뒤 재확인).
2. **사전 진단**: 열린 질문 2~3개. 사용자가 아는 만큼 답한다.
3. **보정**: 틀리거나 빈 부분만 짚는다. 처음부터 강의하지 않는다. 필요 시 힌트/비유.
4. **코드로 확인**: 가능한 주제는 사용자가 직접 실험 코드를 작성(H2, 단위 테스트 등). Claude는 리뷰.
5. **말로 설명**: 면접관에게 설명하듯 답을 쓰게 하고 꼬리 질문을 던진다.
6. **기록**: 아래 파일 갱신.

## 기록
